# Toolcrib — User Guide

The full CLI user guide (install, the `init`/`apply`/`doctor`/`merge`
lifecycle, troubleshooting) lives in the CLI package itself, so it's always
in sync with what `npm install -g toolcrib` actually ships:

**→ [cli/README.md](cli/README.md)** (or [on npm](https://www.npmjs.com/package/toolcrib))

This doesn't cover how to use any individual component — for that, point
your AI assistant at `ai-docs/`, vendored into your project by `toolcrib
init`.
